Offline Resilience — Event Sync Pipeline
    sequenceDiagram
      participant A as DrowsinessAnalyzer
      participant S as Foreground Service
      participant F as Firestore
      participant R as Room DB
      participant W as WorkManager

      A->>S: impairment detected (subtype, severity)
      S->>F: writeEvent(event)

      alt Online — Write Succeeds
        F-->>S: ✅ Event stored
        S->>F: incrementTripCounter()
      else Offline — Write Fails
        F-->>S: ❌ Network error
        S->>R: insert(PendingEventEntity)
        Note over R: Stored locally with retry count
      end

      loop Every 15 minutes (when online)
        W->>R: getPendingEvents()
        R-->>W: List of unsent events
        W->>F: writeEvent(each)
        F-->>W: ✅ Synced
        W->>R: delete(synced events)
      end

10. Driver UI — Camera Status Indicators
Real-time visual feedback via camera preview border color

🟠 Amber — Calibrating

First 15 seconds after monitoring starts. Collects eye-openness baseline to set personalized threshold. No alerts during this phase. Shows "Calibrating (X%)" with progress.

🟢 Green — Active / Recovered

Face detected, all signals within normal range. Monitoring is fully active. Also shown after recovery from an alert (eyes open 2+ seconds). Label: "Monitoring Active" or "Driver Awake — Alarm Stopped".

🟠 Orange — Face Not Detected

ML Kit cannot find a face in the camera frame. Could be caused by sunglasses, poor lighting, or incorrect camera angle. Label: "Face Not Detected — Adjust Camera". No false positives.

🔴 Red — Impairment Alert

One or more impairment signals active. Full-screen red overlay. Alarm at max volume through BT or phone speaker. "Stop Alarm" button appears. Re-alerts every 5 seconds while eyes remain closed.

Camera Preview Controls

The live camera preview can be collapsed using the (−) button to a small 120×90dp thumbnail, reducing driver distraction. The (+) button expands it back to full size. Monitoring continues regardless of preview size.
